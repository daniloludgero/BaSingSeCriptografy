2. GF(2¹⁶) S-Box DDT Uniformity = 4 Verifier

Algebraic + Z3 SMT

For any non-zero input difference Δ_in ∈ [1, 65535], the maximum-probability output difference is Δ_out = Inv(Δ_in), achieved by exactly 4 witnesses: {0, Δ_in, Δ_in·ω, Δ_in·(ω⊕1)} where ω = 0x015E solves x² + x + 1 = 0 in GF(2¹⁶).
